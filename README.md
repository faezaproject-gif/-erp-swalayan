# ERP Swalayan V23 — Android Build

Project Android native WebView untuk ERP Swalayan V23 mode lokal/demo.

## Build APK otomatis di GitHub
1. Upload seluruh isi folder ini ke repository GitHub.
2. Buka tab **Actions**.
3. Pilih **Build APK**.
4. Tekan **Run workflow** (atau push ke `main`).
5. Setelah selesai, buka hasil workflow → **Artifacts** → `ERP-Swalayan-V23-APK`.
6. Download ZIP artifact, ekstrak `app-debug.apk`, lalu install di HP.
